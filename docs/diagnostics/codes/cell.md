# Diagnostic codes: cell area

Codes `CELL-<TOPIC>-<NNN>` emitted by `src/core/src/cell/` (owner: CELL,
`openspec/changes/m1-core-viewer/design.md` D2/D3): `.mag` reading and
writing, library resolution, I/O safety, crash backups, timestamps and the
CELL commands. Conventions and the renderings are described in
[../codes.md](../codes.md).

The table below is generated from `src/core/src/cell/codes.cpp`:

```sh
hefesto-cli --diagnostic-codes=cell
```

The unit test `each area's code table matches its document and prefix`
fails when the two disagree.

Severity convention for this area: `error` marks a read, write or command
that fails (a format error still keeps what was read); `warning` reports a
problem the operation works around (a skipped record, a read-only cell, a
path fallback); `info` is informational. Message texts follow Magic's where
the specs quote them.
