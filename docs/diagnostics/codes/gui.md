# Diagnostic codes: gui area

Codes `GUI-<TOPIC>-<NNN>` emitted by `src/core/src/gui/` (the GUI manager
view models, the DRC report file and the toolbar presets reader; owner:
GUIMGR, `openspec/changes/m4-scripting/design.md` D1/D2). Conventions and
the renderings are described in [../codes.md](../codes.md).

`GUI-WRAP-*`: wrapper windows and their script hooks; `GUI-REPORT-*`:
`drc_save_report`/`drc_load_report`; `GUI-TOOLBAR-*`: the toolbar presets
file read as data (Q-SCRIPT-11, Q-SCRIPT-28); `GUI-PROMPT-*`: the file
prompts. Codes marked "Hefesto only" are `native_only` (the `magic`
diagnostics format drops them). The constants are in
`src/core/include/hefesto/gui/diag_codes.hpp`. The table below is
generated from `src/core/src/gui/codes.cpp`:

```sh
hefesto-cli --diagnostic-codes=gui
```

The unit test `each area's code table matches its document and prefix`
fails when the two disagree.

<!-- BEGIN DIAGNOSTIC CODES (generated by `hefesto-cli --diagnostic-codes=gui`) -->
| Code | Default severity | Meaning |
|---|---|---|
| `GUI-PROMPT-001` | info | A file prompt reports what it read (`Top-level cells read from GDS file: L`, `Cells read from GDS file: L`). |
| `GUI-REPORT-001` | info | `drc_save_report` or `drc_load_report` progress (`loading C`, `done with F`, `Reading F`, `Done.`). |
| `GUI-REPORT-002` | error | The DRC report file cannot be opened or written (Tcl's `couldn't open "F"` error); nothing is written or read. |
| `GUI-TOOLBAR-001` | warning | A statement of the toolbar presets file `<tech>_toolbars.tcl` is not a `set <name> {<layers>}` line; it is ignored and never evaluated (Q-SCRIPT-11). Hefesto only. |
| `GUI-TOOLBAR-002` | error | A toolbar preset cannot be loaded: the presets file `<tech>_toolbars.tcl` is missing or does not set the preset (Q-SCRIPT-28). |
| `GUI-USAGE-001` | error | A GUI manager command was given the wrong number or form of arguments (Tcl's `wrong # args` error of the procedure). |
| `GUI-WRAP-001` | error | A wrapper window cannot be opened or closed (no such frame, or the layout window cannot be created). |
| `GUI-WRAP-002` | info | A wrapper hook script (`Opts(callback)`, `Winopts(F,callback)`) failed; as in Magic the error is caught and the wrapper opens. Hefesto only. |
<!-- END DIAGNOSTIC CODES -->
