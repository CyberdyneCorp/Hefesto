# Diagnostic codes: antenna area

Codes `ANTENNA-<TOPIC>-<NNN>` emitted by `src/core/src/antenna/` (`antennacheck`
and the antenna rules that `lef write` shares; capability antenna-check;
`openspec/changes/m7-extraction/design.md` D2/D3, D17). Conventions and the renderings are described in
[../codes.md](../codes.md).

The area's table is assembled by `src/core/src/antenna/codes.cpp` (owner:
INTEGRATION) from one fragment, owned by ANTENNA. The rows are sorted while
compiling (`src/core/src/diag/sorted_codes.hpp`):

| Fragment | Topics | Owner |
|---|---|---|
| `src/core/src/antenna/codes.inc` | `ANTENNA-CHECK-*` | ANTENNA |

The antenna keywords of the `extract` section are parsed by the one
extract-section reader and report `EXTRACT-STYLE-*` codes
([extract.md](extract.md)).

The M7 scaffold (tasks.md 3.2, 3.3) declared no code. While M7 is in
progress, a command option or function the scaffold declared before its
workstream implemented it fails with the core code `CORE-NOTIMPL-008`
([../codes.md](../codes.md)); INTEGRATION retires it at M7 exit.

## CHECK

Codes of the antenna check. Owner: ANTENNA.

- `ANTENNA-CHECK-001` (info): a line `antennacheck` prints on its output
  stream, as Magic's TxPrintf: the progress lines `Reading extract file.`,
  `Building flattened netlist.`, `Running antenna checks.`, `   <n> gates
  analyzed.` (after every 100 distinct gate nets) and `antennacheck
  finished.`.
- `ANTENNA-CHECK-002` (warning): a line on the error stream, as Magic's
  TxError: `No planeorder specified for this process:  Cannot run antenna
  checks!`, `Point to a window or specify a cell name.` (also when a cell
  is named with no layout window, where Magic dereferences the missing
  window), `Unrecognized flag: <flag>` and `Usage: antennacheck`, and the
  `debug` lines of a violation (`Cell:`, `Antenna violation detected at
  plane <plane>[ contact]`, `Effective antenna ratio <r> > limit <l>`,
  `Gate rect ...`, `Antenna rect ...`).

The `.ext` read and flattening report the EXTFLAT codes
([extflat.md](extflat.md)); a read failure fails the command with that
code. Violations are feedback areas (`Antenna error at plane <plane>`), not
diagnostics.
