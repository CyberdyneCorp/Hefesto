# Diagnostic codes: select area

Codes `SELECT-<TOPIC>-<NNN>` emitted by `src/core/src/select/` (owner: SELECT,
`openspec/changes/m2-interactive-editing/design.md` D1/D2). Conventions and
the renderings are described in [../codes.md](../codes.md).

The table below is generated from `src/core/src/select/codes.cpp`:

```sh
hefesto-cli --diagnostic-codes=select
```

The unit test `each area's code table matches its document and prefix`
fails when the two disagree. Report lines a selection command prints while
it runs (Magic's TxPrintf / TxError text, such as the edit-cell warnings of
`delete`) use the db area's `DB-REPORT-001` / `DB-REPORT-002`.
