# Diagnostic codes: hints area

Codes `HINTS-<TOPIC>-<NNN>` emitted by `src/core/src/hints/` (mask hints;
owner: HINTS, `openspec/changes/m3-drc/design.md` D1/D2). Conventions and
the renderings are described in [../codes.md](../codes.md).

The table below is generated from `src/core/src/hints/codes.cpp`:

```sh
hefesto-cli --diagnostic-codes=hints
```

The unit test `each area's code table matches its document and prefix`
fails when the two disagree. Messages Magic prints for hint values in
`.mag` files and the `property` command keep their existing codes (for
example `DB-PROP-001` and `CELL-READ-007`); this area holds codes for the
hint operations themselves.
