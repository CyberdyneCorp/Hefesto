# Diagnostic codes: extresist area

Codes `EXTRESIST-<TOPIC>-<NNN>` emitted by `src/core/src/extresist/` (resistance extraction: network construction and reduction, the `extresist` command, its `.ext` input model and its `.res.ext`, `.res.lump`, FastHenry and geometry output; capabilities extresist-command, extresist-network and extresist-output;
`openspec/changes/m7-extraction/design.md` D2/D3). Conventions and the renderings are described in
[../codes.md](../codes.md).

The area's table is assembled by `src/core/src/extresist/codes.cpp` (owner:
INTEGRATION) from one fragment per workstream, each owned by that
workstream. The rows are sorted while compiling
(`src/core/src/diag/sorted_codes.hpp`):

| Fragment | Topics | Owner |
|---|---|---|
| `src/core/src/extresist/network/codes.inc` | `EXTRESIST-NET-*` | RESNET |
| `src/core/src/extresist/command/codes.inc` | `EXTRESIST-CMD-*` | RESCMD |
| `src/core/src/extresist/output/codes.inc` | `EXTRESIST-OUT-*` | RESCMD |

The M7 scaffold (tasks.md 3.2, 3.3) declared no code. While M7 is in
progress, a command option or function the scaffold declared before its
workstream implemented it fails with the core code `CORE-NOTIMPL-008`
([../codes.md](../codes.md)); INTEGRATION retires it at M7 exit.

## NET

Codes of network construction and reduction. Owner: RESNET.

- `EXTRESIST-NET-001` (error): `yank_net` or `build_network` was called through the scaffold overload, which has no technology; nothing is built. Callers use the overloads with a `tech::Technology` (`yank_net(cell, technology, YankRequest)`) or a `BuildInput`.
- `EXTRESIST-NET-002` (error): `build_network` was given a geometry whose cell is not a scratch copy made by `yank_net` (design D6, R6): the stitch editor never fractures a cell's own planes.

The messages Magic prints while it builds or reduces a network (`Couldn't find wire at <x> <y>`, `Error: Node with no area.`, `Missing rptr at (<x> <y>).`, ...) are not diagnostics: they are returned in `Network::messages`, in order, for the `extresist` command to print as Magic does.

## CMD

Codes of the `extresist` command, input model and cutoffs. Owner: RESCMD. None yet.

## OUT

Codes of the output files. Owner: RESCMD. None yet.
