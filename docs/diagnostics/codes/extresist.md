# Diagnostic codes: extresist area

Codes `EXTRESIST-<TOPIC>-<NNN>` emitted by `src/core/src/extresist/` (resistance extraction: network construction and reduction, the `extresist` command, its `.ext` input model and its `.res.ext`, `.res.lump`, FastHenry and geometry output; capabilities extresist-command, extresist-network and extresist-output;
`openspec/changes/m7-extraction/design.md` D2/D3). Conventions and the renderings are described in
[../codes.md](../codes.md).

The area's table is assembled by `src/core/src/extresist/codes.cpp` (owner:
INTEGRATION) from one fragment per workstream, each owned by that
workstream. The rows are sorted while compiling
(`src/core/src/diag/sorted_codes.hpp`):

| Fragment | Topics | Owner |
|---|---|---|
| `src/core/src/extresist/network/codes.inc` | `EXTRESIST-NET-*` | RESNET |
| `src/core/src/extresist/command/codes.inc` | `EXTRESIST-CMD-*` | RESCMD |
| `src/core/src/extresist/output/codes.inc` | `EXTRESIST-OUT-*` | RESCMD |

The M7 scaffold (tasks.md 3.2, 3.3) declared no code. Every option and function the M7 scaffold declared is implemented; its stub
code `CORE-NOTIMPL-008` is retired (M7 round 5, tasks.md 19.5;
[../codes.md](../codes.md)).

## NET

Codes of network construction and reduction. Owner: RESNET.

- `EXTRESIST-NET-001` (error): `yank_net` or `build_network` was called through the scaffold overload, which has no technology; nothing is built. Callers use the overloads with a `tech::Technology` (`yank_net(cell, technology, YankRequest)`) or a `BuildInput`.
- `EXTRESIST-NET-002` (error): `build_network` was given a geometry whose cell is not a scratch copy made by `yank_net` (design D6, R6): the stitch editor never fractures a cell's own planes.

The messages Magic prints while it builds or reduces a network (`Couldn't find wire at <x> <y>`, `Error: Node with no area.`, `Missing rptr at (<x> <y>).`, ...) are not diagnostics: they are returned in `Network::messages`, in order, for the `extresist` command to print as Magic does.

## CMD

Codes of the `extresist` command, input model and cutoffs. Owner: RESCMD.

- `EXTRESIST-CMD-001` (info): a line on the output stream, as Magic's
  TxPrintf: an on/off query (`on`, `off`), a net list (`force`, `ignore`,
  `include` without a name, in Magic's hash-table order), `Extracting
  <net>` (with ` (Rnode = <r>ohm ; Rthresh = <t>ohm)` under `debug`),
  `Not adding <net> (maxres = <r>ohm)` under `debug`, and the statistics
  (`Total Nets: ...` or `Total Nodes: 0`), `Writing FastHenry-format
  geometry file "<cell>.fh"`, `Port <p> reassigned index <i>`
  (`fasthenry`), and the resistors of `extresist box <type>`
  (`r (<x1>,<y1>) (<x2>,<y2>) r=<milliohms>`).
- `EXTRESIST-CMD-002` (warning): a line on the error stream, as Magic's
  TxError: `Value must be either "on" or "off".`, `Usage:  extresist
  threshold|minres|mindelay [value]`, `Unrecognized layer (type) name
  "<t>"` or `Ambiguous layer (type) name "<t>"` from `skip` (no mask
  changes, Q-NETLIST-23), the `tolerance` deprecation note, the FastHenry
  frequency notes, `No cell selected`, `Couldn't find def corresponding to
  box`, `Couldn't open output file`, `Node <n> has force label but no
  drive point or driving device`, `Error in extracting node <n>`, an output
  net's `Missing <gate|substrate|source|drain|terminal> connection of
  device at (<x> <y>) on net <n'>` and `Warning:  Orphaned node "<n>"
  arbitrarily attached to "<node>"` (ResFixUpConnections and the orphan
  patch), `Warning: contention over node X|Y position` (FastHenry and
  geometry node alignment) and `Put the cursor in a layout window.`
  (`geometry` with no layout window).
- `EXTRESIST-CMD-003` (error): an output file could not be written or
  committed through extract::AtomicOutput; the previous file is kept.
- `EXTRESIST-CMD-004` (warning): the run was cancelled; no `.res.ext`,
  `.res.lump` or `.fh` of the cell was written (Q-EXTRACT-27).

## OUT

Codes of the `.ext` input model and the output files. Owner: RESCMD.

- `EXTRESIST-OUT-001` (error): `Cannot open file <cell>.ext`; the run
  prints it and goes on with the next cell.
- `EXTRESIST-OUT-002` (warning): a message of ResReadExt: `<file>, line
  <n>: Unrecognized token ...` or `Not enough tokens ...`, `Bad tile type
  name ...`, `Unknown node name ... in .ext file connect entry`, `Bad
  device <d>:  Too few arguments in .ext file`, `Warning: Node <n> is both
  forced and skipped`, an `attr` record before any node record (both
  modes) or, with magic-compat OFF, for an unknown node (Q-NETLIST-29).
- `EXTRESIST-OUT-003` (info): the `debug` lines `Added port|sink|driver
  at <llx> <lly> <urx> <ury>`.
