# Diagnostic codes: cif area

Codes `CIF-<TOPIC>-<NNN>` emitted by `src/core/src/cif/` (CIF read and write and the `cif` command;
`openspec/changes/m5-mask-gds-cif/design.md` D1/D2). Conventions and the
renderings are described in [../codes.md](../codes.md).

The area's table is assembled by `src/core/src/cif/codes.cpp` (owner:
INTEGRATION) from one fragment per workstream, each owned by that
workstream. The rows are sorted while compiling
(`src/core/src/diag/sorted_codes.hpp`):

| Fragment | Topics | Owner |
|---|---|---|
| `src/core/src/cif/read/codes.inc` | `CIF-READ-*` | CIF |
| `src/core/src/cif/write/codes.inc` | `CIF-WRITE-*` | CIF |
| `src/core/src/cif/command/codes.inc` | `CIF-CMD-*` | CIF |

While M5 is in progress, an option or function the scaffold declared before
its workstream implemented it fails with the core code `CORE-NOTIMPL-005`
([../codes.md](../codes.md)).

## CIF

Codes of the CIF parser and its symbol table (`CIF-READ-*`), the CIF writer (`CIF-WRITE-*`) and the `cif` command (`CIF-CMD-*`) (`src/core/src/cif/`; capability cif-format-io; design D13).

### CIF parser (`CIF-READ-*`, `src/core/src/cif/read/`)

The parser reports Magic's read messages with Magic's text and prefixes
(capability cif-format-io "Read diagnostics"): `CIF-READ-001` carries a
CIFReadError ("Error at line L of CIF file: ...", or "CIF file read error:
..." at line 0) and `CIF-READ-002` a CIFReadWarning. Both are counted per
read; warning level `limit` prints the first 99 of each and then
`CIF-READ-003` once, level `none` prints nothing, and level `redirect` sends
them to the redirect file with magic-compat OFF only (Q-MASK-331).

`CIF-READ-004` and `CIF-READ-005` are the wire messages Magic prints outside
the counters (CIFPaintWirePath): a direction reversal or repeated point,
where the wire is split, and a junction past the mitre limit, where the rest
of the route is dropped ("Route has been truncated.").

`CIF-READ-006` is Hefesto's own (`native_only`): a read creates at most a
fixed number of cells (a resource cap against malformed files); the symbols
past it are ignored, with their geometry. An element whose coordinates leave
the usable plane is ignored with the database code `DB-GEOM-001`, as the
`.mag` reader does.

`CIF-READ-007` is Magic's "Warning: CIF reading is not undoable!  I hope
that's OK." printed when `cif read` starts, `CIF-READ-008` Magic's "Don't
know how to read CIF:  nothing in tech file." when no cifinput style is set,
and `CIF-READ-009` "Cannot open <name>.cif to read CIF." when the file is not
found along the cell search path or cannot be read. The read engine's grid
messages are printed as `CIF-READ-002` warnings and its boundary
redefinition as a `CIF-READ-001` error, with the line prefix, as Magic's
CIFReadWarning and CIFReadError print them.

### CIF writer (`CIF-WRITE-*`, `src/core/src/cif/write/`)

`CIF-WRITE-001` refuses a write without an output style (Magic dereferences
a null style); no file is touched. `CIF-WRITE-002` is Magic's "Failure to
read in entire subtree of the cell." with the cell that failed, and
`CIF-WRITE-003` the refusal of a style whose reducer is 0 ("can only be used
for writing Calma output"); after either the output file is left empty and
`CIF-WRITE-004` follows with "I/O error in writing file <name>." and "File
may be incompletely written.", as CmdCif reports a failed CIFWrite.
`CIF-WRITE-004` also reports a file that cannot be opened ("Cannot open
<name>.cif to write CIF"). `CIF-WRITE-005` is the "<n> problems occurred.
See feedback entries." line after a write whose generation reported
problems. `CIF-WRITE-006` reports label text with whitespace or `;`
(Q-MASK-322): with magic-compat ON the text is written verbatim and the
warning is Hefesto's own (`native_only`); with it OFF the characters become
`_` and the warning has the GDS writer's form. `CIF-WRITE-007` is a
cancelled write (no file is left) and `CIF-WRITE-008` a hierarchy deeper
than the subtree loader's limit.

### `cif` command (`CIF-CMD-*`, `src/core/src/cif/command/`)

`CIF-CMD-001` (`native_only`) warns that `cif unfracture yes` or `no` did
not set the switch with magic-compat ON, where Magic reads the value from the
fourth word only (Q-MASK-413). `CIF-CMD-002` is the "<n> problems occurred.
See feedback entries." line of `cif see`, `paint`, `coverage` and the
`*hier`/`*array` previews, and `CIF-CMD-003` reports that no output style is
set for them.
