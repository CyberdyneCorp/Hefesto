# Diagnostic codes: pcell area

Codes `PCELL-<TOPIC>-<NNN>` emitted by `src/core/src/pcell/` (the gencell
framework and the native generators; owner: PCELL,
`openspec/changes/m4-scripting/design.md` D1/D2). Conventions and the
renderings are described in [../codes.md](../codes.md).

The table is assembled by `src/core/src/pcell/codes.cpp` (owner:
INTEGRATION) from `src/core/src/pcell/framework/codes.inc` and
`src/core/src/pcell/native/codes.inc` (owner: PCELL), sorted while
compiling.

## Framework

The gencell framework (`pcell/framework/`, Magic's `toolkit.tcl` ported to
C++; tasks.md 7.1-7.4).

- `PCELL-GEN-001` is the script error a framework procedure raises where
  `toolkit.tcl` raises one: `No import routine for <lib> library cell
  <type>!`, `No gencell device is selected!`, Tcl's `wrong # args` and
  `dict create` messages, an error of a device procedure that the framework
  does not catch (`_defaults`, `_convert`, `_dialog`), and the Tk errors of
  the dialog procedures when no dialog exists (`bad window path name
  ".params.body.area.edits"`). The text is the Tcl error message.
- `PCELL-GEN-002` is the framework's `puts stderr`: a `_check` or `_draw`
  error caught by the create and change algorithms (generation continues
  with the unchecked parameters or the partly drawn cell), and the line
  parse errors of `netlist_to_layout`. The text is what Magic prints.
- `PCELL-GEN-003`: a framework procedure ran in a session whose project has
  no script interpreter (`EditorState::script.interp` is null).
- `PCELL-LIST-001`: a parameter dictionary or list argument is not a valid
  Tcl list (Tcl's message, e.g. `unmatched open brace in list`, or `missing
  value to go with key`).
- `PCELL-NETLIST-001` is `netlist_to_layout`'s `puts stdout` report
  (`Creating layout from ...`, `Cell <name> already contains layout.
  Skipping generation.`, ...).

## Native generators

No code yet (tasks.md 7.5-7.7). The PDK helpers report a call they cannot
reproduce bit for bit by returning no value, and the caller runs the Tcl
generator; no native generator is built in yet.

## Table

```sh
hefesto-cli --diagnostic-codes=pcell
```

The unit test `each area's code table matches its document and prefix`
fails when the two disagree.
