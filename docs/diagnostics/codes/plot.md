# Diagnostic codes: plot area

Codes `PLOT-<TOPIC>-<NNN>` emitted by `src/core/src/plot/` (the `plot`
command: the technology `plot` section, the plot parameters, the plotted
region, atomic output files, the PostScript and PNM writers; capability
plot-output; `openspec/changes/m10-plot-route/design.md` D3).
Conventions and the renderings are described in [../codes.md](../codes.md).

The area's table is assembled by `src/core/src/plot/codes.cpp` (owner:
SCAFFOLD) from one fragment per workstream, each owned by that workstream.
The rows are sorted while compiling (`src/core/src/diag/sorted_codes.hpp`):

| Fragment | Topics | Owner |
|---|---|---|
| `src/core/src/plot/tech/codes.inc` | `PLOT-TECH-*` | PLOTTECH |
| `src/core/src/plot/params/codes.inc` | `PLOT-PARAM-*` | PLOTCMD |
| `src/core/src/plot/cmd/codes.inc` | `PLOT-CMD-*` | PLOTCMD |
| `src/core/src/plot/io/codes.inc` | `PLOT-IO-*` | PLOTCMD |
| `src/core/src/plot/ps/codes.inc` | `PLOT-PS-*` | PS |
| `src/core/src/plot/pnm/codes.inc` | `PLOT-PNM-*` | PNM |

The view export (`display/export/`, owner EXPORT) is part of the display
area: its codes are `DISPLAY-EXPORT-*` in [display.md](display.md).

The scaffold (tasks.md 3.1) declared no code. Until a workstream lands its
part, the `plot` command and the area-contract functions report
`CORE-NOTIMPL-010` ([../codes.md](../codes.md)).

## PLOTTECH

Codes of the technology `plot` section reader (`plot/tech/`; "Technology
plot section structure", "PostScript style lines", "PNM style lines",
"Raster printer and legacy plot devices"). None yet.

## PLOTCMD

Codes of the `plot` command, the plot parameters, the plotted region and
the atomic output files (`plot/cmd/`, `plot/params/`, `plot/io/`; "Plot
command and plotted region", "Plot parameters", "Plot output safety and
limits"). None yet.

## PS

Codes of the PostScript writer (`plot/ps/`; the "PostScript ..."
requirements). None yet.

## PNM

Codes of the PNM writer (`plot/pnm/`; "PNM rasterisation and file format",
"Platform mechanism of plot output"). None yet.

## EXPORT

The SVG and PNG view export reports `DISPLAY-EXPORT-*` codes
([display.md](display.md)); `plot svg` reports them through `plot`. None
yet.
