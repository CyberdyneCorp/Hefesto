# Diagnostic codes: tools area

Codes `TOOLS-<TOPIC>-<NNN>` emitted by `src/core/src/tools/` (`readspice`
and the auxiliary tools; owner: TOOLS,
`openspec/changes/m4-scripting/design.md` D1/D2). Conventions and the
renderings are described in [../codes.md](../codes.md).

`TOOLS-RSP-*`: `readspice` (capability readspice); `TOOLS-STRIP-*`: the
reference-library stripper; `TOOLS-MAZE-001`: `mazeroute` until
`router-maze-iroute` (M10, Q-SCRIPT-30). The constants are in
`src/core/include/hefesto/tools/diag_codes.hpp`. The table below is
generated from `src/core/src/tools/codes.cpp`:

```sh
hefesto-cli --diagnostic-codes=tools
```

The unit test `each area's code table matches its document and prefix`
fails when the two disagree.

| Code | Default severity | Meaning |
|---|---|---|
| `TOOLS-MAZE-001` | error | `mazeroute` is not available yet: it arrives with the maze router `iroute` (router-maze-iroute, M10). |
| `TOOLS-RSP-001` | info | `readspice` progress (`Annotating port orders from F`, `Annotating cell C`, `Cell C port order was modified.`, `Cell C in netlist has not been loaded.`). |
| `TOOLS-RSP-002` | warning | `readspice` cannot read the netlist file or any of its extension candidates (`Error:  Can't read netlist file F`); the result is 1. |
| `TOOLS-RSP-003` | warning | A `.PININFO` entry names a pin that the subcircuit line did not list (`.PININFO error:  Pin P not found.`). |
| `TOOLS-RSP-004` | warning | `readspice` could not walk the ports of a cell (`Error:  C port numbering failed.`); the remaining ports keep their indices. |
| `TOOLS-STRIP-001` | info | The reference-library stripper cannot open or rewrite a `.mag` file (`Error: can't open file F`, printed on stdout); the next file is processed. |
| `TOOLS-USAGE-001` | error | A tools command was given the wrong number of arguments (Tcl's `wrong # args` error of the procedure). |
