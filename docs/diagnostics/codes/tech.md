# Diagnostic codes: tech area

Codes `TECH-<TOPIC>-<NNN>` emitted by `src/core/src/tech/` (owner: TECH,
`openspec/changes/m1-core-viewer/design.md` D2/D3). Conventions and the
renderings are described in [../codes.md](../codes.md).

The table below is generated from `src/core/src/tech/codes.cpp`:

```sh
hefesto-cli --diagnostic-codes=tech
```

The unit test `each area's code table matches its document and prefix`
fails when the two disagree.

Severity convention for this area: `error` marks a problem that makes the
technology load (or the command) fail; `warning` is reported while the load
goes on; `info` is informational. Location headers name the file and line
being read (an included file while inside an `include`).
