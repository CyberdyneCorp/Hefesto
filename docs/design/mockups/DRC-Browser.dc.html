DRC results browser

The DRC panel docks beside the canvas and lists the root cell's errors grouped by why-text, as Magic's DRC manager does (select top cell + drc listall why). Every control issues a drc command, so it is logged and replayable. The inspector shows the error area under the box. Later-milestone parts of the M1 board (measured versus required, nets, suggested fix, Fix with agent, sign-off) stay visible but disabled, each naming its milestone.

Notes for SHELL

  • 1Style selector lists drc listall style and issues drc style <name>. Error tiles were made under the previous style, so the list then marks itself stale. Re-check issues select top cell; drc check; drc catchup (Magic's DRC manager also selects the top cell first). Disabled while the checker is busy.
  • 2Summary: error tiles are the root cell's drc list count total, the number Magic's title bar shows (DRC=12). Areas are the rectangles of drc listall why, which can be more than the tiles. Both are shown so neither looks wrong.
  • 3Virtual Raven Table built from select top cell + drc listall why (200,000-row scenario). Groups are why-texts with their area count, sortable by text or count; their order from Magic is unspecified, so the default sort is by count. Expanding a group lists its rectangles in discovery order. Clicking one issues box values … + findbox zoom, as Magic's DRC manager does.
  • 4Ignored: drc listall why still returns ignored texts, so they are listed here, dimmed, with ◆ counts. Clear ignores issues drc ignore none; Magic has no command to unignore one rule. With magic-compat on, the last why-text of the style cannot be ignored (Q-DRC-17): it stays in the main list.
  • 5Prev/Next issue drc find k−1 / drc find k+1 with an explicit index (wrapping n→1), so the first Next does not jump to #2 under magic-compat (Q-DRC-15). #k of n: k from the last drc find, n = error tiles. Keys stay Magic's (! = drc find; findbox zoom; zoom 16).
  • 6Canvas: error tiles in Magic's error_waffle style (white offset waffle, stipple 4), the box on the found tile, and a canvas-token tag with #k and the why-text of drc find. The group and rectangle rows that overlap the box are highlighted.
  • 7Sign-off summary of the M1 board: collapsed and disabled until M13 (tooltip names it). Fix with agent (toolbar) is disabled until M11.
  • 8Inspector shows the error area under the box: the why-texts that drc find printed (or drc why for a clicked rectangle), cell, area, size and style. Zoom to issues findbox zoom; Why here issues drc why.
  • 9Ignore issues drc ignore <text> (case-sensitive substring of the unsubstituted why-text), prefilled with the rule tag in parentheses. The chip count does not drop: ignored rules still make tiles.
  • 10Measured versus required, nets and suggested fix (with Preview fix) of the M1 board are disabled rows naming M11 / M7 / M11 in their tooltips. The M1 tech-file rule excerpt is hidden: no drc command reports a rule's source.
