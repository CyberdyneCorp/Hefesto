M3 · Design rule checking

DRC status: top bar and status bar

The static M1 chip "◆ DRC not run" becomes live. The chip and the status-bar segment follow drc::DrcEvents (busy / idle) and the root cell's error-tile count, the number Magic's title bar shows as DRC=N. Status is never color-only: every state has a shape and a word. Clicking the chip opens the DRC panel; its menu holds the DRC commands of Magic's Drc menu.

Notes for SHELL

  • 1Chip: a button whose accessible name carries state, count and style ("DRC: 12 errors, style drc(full). Open the DRC panel"); state changes are announced politely. Click opens the DRC panel; the chevron or right-click opens the menu.
  • 2Menu: Check now = select top cell; drc check; drc catchup; Find next = drc find; findbox zoom; Why = drc why; Background checking = drc on / drc off (checked from drc status); Style ▸ = drc listall style → drc style <name>.
  • 3Precedence: off › checking › not run › N errors › clean. N is the root cell's drc list count total, read on idle (as Magic's magic::drcstate idle). Shapes: ◆ info/neutral, ● clean, ■ errors.
  • 4drc why output (also from the command bar) opens a popover at the box, one row per why-text in order of discovery; "No errors found." in the clean case. It closes on Esc or the next command. Error tiles keep Magic's error_waffle stipple.
  • 5While checking, the Dock icon shows an indeterminate progress badge: DrcEvents only reports busy and idle, so there is no fraction to show.
