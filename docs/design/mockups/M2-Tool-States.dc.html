M2 · Interactive editing

Editing tools — rail and canvas states

Every rail tool is live in M2 (place device stays disabled until M4). The active tool comes from ui::ToolRegistry; Box, Select and Wire are Magic's box, pick and wiring tools, while Paint, Label and Measure are Hefesto modes built on the box tool that issue ordinary commands. Canvas feedback is drawn with highlights in white only; the ember accent never touches canvas geometry.

Notes for SHELL

  • 1Box: the box is Magic's solid white 2 px outline (ui-windows-and-views "Box display"), not the M1 board's dashed box. The corner cursor switches between glyphs 6 and 5 while a button is held.
  • 2Select: press selects under the cursor; dragging shows the floating selection as a dashed white ghost with a Δ chip; release issues move (⇧ = copy). Nothing changes until release.
  • 3Paint: the active palette layer (layer board) is the paint type. Without an active layer the tool is disabled with the tooltip "Choose a layer to paint".
  • 5Label and Measure: the popover and ruler are canvas overlays in canvas tokens; every action is logged in the Console as the command it issued.
