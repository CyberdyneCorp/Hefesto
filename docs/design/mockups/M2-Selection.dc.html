Fields that differ across items are hidden; pick a row to narrow the selection.

  • 1Paint: Move fields issue move dx dy; Select net issues select net; What prints what to the Console.

  • 2Label: each field issues setlabel (text, layer, font, size, rotate, justify, sticky) on the selected labels; Make port issues port make.

  • 3Port: Index, Class, Use and Connects issue port index, port class, port use, port connects; equivalent ports share the index.

  • 4Instance: id → identify X1; orientation → orient; array fields → array; Expand → expand selection; Edit cell → edit; Lock → instance lock.

  • 5Mixed: rotate/flip/move act on everything (clockwise, sideways, upsidedown, move). With nothing selected the inspector keeps the M1 BOX/CELL view.
