M4 · Scripting and PDK integration

Tcl console

The Console tab of the bottom dock becomes the project's Tcl console. It evaluates in the project's sandboxed interpreter (script::Interpreter::evaluate), the same interpreter that ran the PDK scripts, so procedures, variables and magic:: commands are all there. Input is multi-line. Output keeps stdout, stderr, results and errors apart by shape and color. A script that runs long can be interrupted. The one-line command bar stays where it is and sends its lines to the same interpreter; their transcript shows here.

Notes for SHELL

  • 1The Console tab of the bottom dock (M2 panels), 12 px JetBrains Mono, transcript newest at the bottom. It keeps the last 10,000 lines. Save… writes the transcript to a file through the file picker.
  • 2Line kinds: % input (ember prompt) and > continuation; plain stdout (puts); results in secondary text; ▲ stderr lines in the warning color; ■ Tcl errors in the danger color with their code. Shape plus color, never color alone. The All / stderr filter hides the rest.
  • 3Output routed through OutputRouting: puts text is literal (a $ stays a $, Q-SCRIPT-4), and engine messages from magic:: commands appear in order with script output.
  • 4Sandbox denials are Tcl errors in the transcript and also ■ Diagnostics rows (M4-Script-Consent); the Diagnostics count updates.
  • 5Multi-line input: Return runs the input only when it is a complete Tcl command (info complete); otherwise it inserts a new line and the hint shows what is open ("1 open brace"). Shift-Return always inserts a line. ↑/↓ walk the shared history (the command bar's), Tab completes commands, procedures and variables.
  • 6Header: Interrupt (enabled only while running), Clear, Save…, collapse. The command bar below the canvas stays one line and runs through the same interpreter.
  • 7Running: input typed meanwhile is queued (Magic's terminal input queue) and runs after the script, in order.
  • 8An interrupt is reported as Tcl reports it (eval canceled), with the line when known.
  • 9With several windows, Window Command Entry gives each its own prompt; the project console keeps %.
