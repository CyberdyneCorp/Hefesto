Color window

specialopen color 047 opens Magic's color editor as an undocked window. The drawing surface is Magic's fixed layout drawn by the renderer in the display styles (canvas, dark in both themes); Hefesto only adds forge chrome around it: the caption, an index stepper, Load/Save and a read-only value strip.

Notes for SHELL

  • 1Surface: six bars with − / + pumps, swatch and the Color Being Edited title at Magic's coordinates (ui-color-window layout table), bar fills in the red, green, blue, yellow, gray and brown-1 styles, outlines and text in the bounding-box style. The pressed pump shows a 2 px outline while held.
  • 2Every change is one undo step of the color map; the window's u/U and the top-bar buttons undo it.
  • 3Caption is COLOR = 0<octal>. The ▲ chip appears once the map is modified; Load… and quit then ask the unsaved-color-map question (dialog board). Save… issues save with the chosen style names; Load… load.
