Undo and redo

Undo and redo sit in the top bar right after Open/PDKs, as 32 px ghost icon buttons. Their tooltip and accessible name carry the step they act on. Holding (or right-clicking) Undo opens the history. Keys stay Magic's: u undo, U redo.

Clicking a step issues undo N or redo N. The list is the log of undo print, described in words.

Notes for SHELL

  • 1Tooltip: "Undo <description>" from undo::Event::describe of the newest step, plus the key. The macOS Edit menu, if SHELL adds one, uses the same text and issues the same undo/redo commands.
  • 2Buttons follow the log only: they never change state between commands. In a color window the same buttons act on the color map (its client registers undo/redo).
  • 3History: newest first, the redo tail above the current-state line in tertiary text. One undo step is one user command (a drag is one step). The note line shows the limit from undo-history-limit.
  • 4After undo/redo the status bar names the step and offers the inverse; the canvas only redraws, it does not move the view.
