Dockable and collapsible panels

Layers, Hierarchy, Inspector, Console/Diagnostics/Feedback and the color window are panels. Each docks left, right or bottom, floats, or collapses; the canvas always takes the rest.

A dock collapsed to its edge keeps a 28 px strip of vertical tabs; clicking a tab opens it as an overlay (200 ms slide, none with reduced motion), double-click pins it open.

Notes for SHELL

  • 1Floating panel: popover elevation, 8 px radius, a header bar in the bar token; Dock returns it to the dock it came from. Floating panels stay inside the window.
  • 2Dragging a header shows a ghost and highlights the target dock with a dashed ember zone (14 % tint); dropping on a dock with panels adds a tab. Esc cancels.
  • 3Collapsed: the Hierarchy header stays as a 32 px row with its count; the bottom area collapses to its tab strip. Layout (dock, size, collapsed, floating) is saved per user in settings and restored at launch; a Reset layout command restores the default (M1 arrangement).
  • 4Keyboard: F6 cycles focus across docks; every header button has an accessible name with its state ("Hierarchy, collapsed"). At 1024 × 640 the right dock collapses to its edge strip first.
