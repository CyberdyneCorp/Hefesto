M4 · Scripting and PDK integration

Menu bar and PDK device menus

The desktop gets Magic's wrapper menus: File, Edit, Cell, Window, Layers, Drc and Options, from gui::WrapperMenuModel. The menus a PDK script adds through Opts(callback) come after them, from script::MenuModel; for sky130 these are Devices 1 and Devices 2. Every item issues a logged command, as in Magic. The intercepted widget calls add two PDK items to the wrapper menus: Import SPICE in File and DRC Routing in Drc. The menus have one model and two renderings: the native menu bar on macOS, and a 30 px bar inside the window on Linux.

Notes for SHELL

  • 1On Linux the bar sits between the top bar and the work area: 30 px, bar token, 13/500 labels, 6 px radius on hover and open. F10 focuses it; ←/→ move between menus, ↓ opens one. The top bar is unchanged.
  • 2The PDK menus come after a divider, in the order of the PDK's add_toolkit_menu calls. A PDK menu that is open has the ember tint, so it reads as PDK content. Its labels are the PDK's own text.
  • 3The first row names the menu's source (pdk1, the script). An item runs its command: magic::gencell sky130::<device> opens the Place device dialog (M4-PCell-Dialog), and a <ns>::*_draw item paints at the box. Long menus scroll as native menus do.
  • 4When an item is hovered or focused, the status bar shows its label and command. The command is also the item's accessible description.

Notes for SHELL

  • 5macOS: a native NSMenu built from the same items and rebuilt on ScriptEvents::on_menu_model_changed. Quit and Save All and Quit stay in File, as Magic has them; ⌘Q in the app menu also runs magic::quit.
  • 6The labels are Magic's (PDK scripts insert items by index, and Magic users know the labels). Magic's double spaces are collapsed. Rotate 90 degree runs magic::clockwise 90 (Q-SCRIPT-36). An accelerator is shown only when a key macro's text equals the item's command, so Zoom In (zoom 0.5) has none and the z macro (zoom .5) does not match it.
  • 7Import SPICE is inserted by sky130's file.toolmenu insert 4, which Hefesto intercepts. It lands between two separators after Flush changes and runs sky130::importspice, which opens the native file picker and then magic::netlist_to_layout <file> sky130. The PDK chip tells the user that the item came from the PDK. Read and Write GDS are disabled until M5.
  • 8Reorder layers opens the reorder dialog (M4-Managers). Protect and Unlock Base Layers run tech revert and tech unlock *.
  • 9DRC Routing is appended by the PDK (drc style drc(routing)). DRC Fast and DRC Complete set the style; the M3 chip menu keeps Background checking.
  • 10Options check items show and hide the M4 panels: Toolbar is the layer palette in toolbar order, and the managers are panels (M4-Managers). Colormap Window opens the M2 color window, and Window Command Entry shows this window's console prompt (M4-Console). Netlist Window (M12) and 3D Display (M10) are disabled with their milestone; Maze Router appears only when its helper is loaded (M10).
  • 11Each statement skipped by WidgetInterceptor is one ▲ Diagnostics row: code, script file and line, the statement, and the procedure it ran in. Evaluation continues. A clean PDK (the three verified PDKs) produces no row and no message.
