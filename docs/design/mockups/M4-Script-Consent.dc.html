M4 · Scripting and PDK integration

Script consent, trust and the sandbox

Nothing in an opened file runs code without consent (X-3). Before a PDK startup script runs, Hefesto asks once, through script::ConsentHost. The prompt shows where the script comes from and which PDK version it belongs to. There are three answers: Don't run (the file opens read-only with the minimum technology), Run once, or Trust this version, which is stored in the PDK store. Sandbox denials and long-running scripts are reported in the window and never stop the app.

Notes for SHELL

  • 1A modal alert dialog over the scrim, M2 dialog style: a shield icon, a question as the title, a body that says what runs and what the sandbox allows. Shown once per PDK version; if several windows open the same PDK at once, they share one prompt.
  • 2Origin block: the script path (middle-ellipsized, with the full path in the tooltip and selectable), the PDK name and version from the tech file, the store release and whether its digest verified, and what else runs after it. The data is ConsentRequest.
  • 3Answers map to ConsentDecision: Don't run = decline, Run once = run_once, Trust = trust_version. Return runs the focused default (Run once); Esc answers Don't run. The CLI declines in batch mode unless --trust-pdk is given.
  • 4A script found outside the PDK store (auto-discovery) gets a ▲ warning release row, no Trust answer, and Don't run as default.
  • 5The PDK panel gains a scripts state per installed version: ● scripts trusted (with the date) and Revoke trust, or ◆ ask before running and Trust scripts. Both are logged commands (new pdk trust / pdk untrust; PDKINT).
  • 6Declined: a ▲ read-only chip next to the cell name, a banner over the canvas, and disabled editing tools, Place device and save. The canvas shows what minimum can draw. Review scripts… opens the consent prompt again; a yes reloads the project.
  • 7Each denied operation is one ■ Diagnostics row: code, operation, script file and line, the statement. It is also announced in the status bar with a Show link. A denial absorbed by the script's own catch is still listed, marked "caught".
  • 8A script that runs longer than 2 s (PDK startup, generator, console input) shows a non-modal progress card over the canvas with the current file and line and Interrupt (Ctrl-C; request_interrupt). The canvas is dimmed and takes no input until it ends. An interrupt is reported like any Tcl error.
