# Icons

Hefesto's UI icons (capability `hefesto-design-system`, requirement "Icons"):
1.6 px stroke drawings on a 24 px grid, filled only for an active state.
Drawn in white and tinted by the shell with the theme's icon color, so one
file serves both themes. Paths follow the reference mockups
(`docs/design/mockups/Desktop-Layout.dc.html`, `Main.dc.html`).

License: Apache-2.0 (Hefesto's own artwork).

| File | Use |
|---|---|
| box, select, paint, wire, label, measure, place | tool rail |
| fit | zoom to fit |
| eye, eye-off, lock | layer visibility and lock |
| undo, redo | top bar: undo and redo (M2) |
| agent, 3d | top bar / later milestones |
| open, pdk | top bar: open a cell, PDK manager |
