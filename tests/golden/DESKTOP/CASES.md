# Golden Test Cases — DESKTOP area (Desktop Alpha)

The M4 exit check of docs/roadmap.md ("Desktop Alpha", m4-scripting design D18): on each PDK, start with the PDK's rc file (trusted), open a design from its standard-cell library, edit it (paint, label, move), place one generated device of each native family and one Tcl-only device through `magic::gencell`, run `drc check; drc catchup`, save. The scripts are `tests/e2e/desktop_alpha_<pdk>.tcl`; Magic and hefesto-cli run the same file with the same options, and the console (each step's code and result, `drc listall why` among them) and every saved cell are compared. CI runs the cases on Linux x86_64, Linux aarch64 and macOS arm64.
