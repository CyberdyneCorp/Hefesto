# m8-schematic

M8 Schematic capture (`schematic-file-format`, `schematic-symbols-and-libraries`, `schematic-editing`, `schematic-netlisting`, `schematic-simulation-integration`, `schematic-command`): xschem-compatible `.sch`/`.sym` read and write, the PDK symbol libraries of sky130, gf180mcu and IHP with a clean-room system library, the sandboxed `tcleval` and `xschemrc` support, in-process SPICE netlisting in simulation and LVS modes with the `xschem-compat` setting, the schematic editor on desktop, the `schematic` and `xschem` commands, testbench decks ready for M9, the SCHEM golden cases captured from xschem 3.4.8RC with gawk, and the M8 exit check. Implementation follows the two-team clean-room process of `hefesto-licensing`. Its decisions (`docs/decisions/m8-decision-table.md`, the 24 open SCHEM entries, D-21 and judgement items J-1 to J-5) were approved by the user on 2026-11-13; design Open Questions 1–3 were decided the same day, each as option (a).
