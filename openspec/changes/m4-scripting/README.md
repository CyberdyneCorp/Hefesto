# m4-scripting

M4 Scripting and PDK integration (Desktop Alpha): the PDK pin move, an embedded sandboxed Tcl with the `magic::` command namespace and tag callbacks, consent before PDK scripts, the sky130, gf180mcu and IHP sg13g2 startup and device scripts with their menus, the gencell PCell framework with generator dialogs and native C++ generators validated against the Tcl ones, `readspice`, the auxiliary tools, the GUI managers on the desktop, the shell items carried from M2, the 89 SCRIPT golden cases and the Desktop Alpha exit check on Linux and macOS
