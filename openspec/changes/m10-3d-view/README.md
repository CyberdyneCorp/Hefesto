# m10-3d-view

M10 3D view (`view-3d`, `hefesto-3d-visualization`), in three phases: (P1) a slice from layout (magic) layers, started after M5's mask-generation workstream (GEN) lands: the layer stack from extract `height` and cifoutput `render` statements, the `wind3d` window and Magic's 3D commands, camera presets, layer visibility, picking linked to the 2D view and net highlighting; (P2) the mask-layer source, cross-sections and glTF/STL export; (P3) parasitic and field overlays after M7 extraction. Drafted against the recommended answers of `docs/decisions/m10-3d-decision-table.md`, which are not yet approved. The rest of M10 (plotting, diff, routing, EM/IR, digital flow) is not part of this change.
