# m5-mask-gds-cif

M5 Mask generation, GDS and CIF: the cifoutput and cifinput readers with every operator, flat and hierarchical mask generation, the use-enumeration order of Magic's cell-use index (Q-MASK-204), GDS read and write with compressed files, read-only vendor views and content-hash timestamps, CIF read and write, DRC rules on generated mask layers (DRC-CIF-2..7), the `gds`/`calma` and full `cif` commands, the library GDS data of sky130, gf180mcu and IHP with the round-trip check against Magic, the 233 MASK golden cases and the M5 exit check
